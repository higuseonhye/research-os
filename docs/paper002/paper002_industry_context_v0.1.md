## Macro trend (2024–2026)

```text
generalist policy / VLA / large behavior models
        ↓
world foundation models + synthetic data + simulation
        ↓
generation + reasoning + action simulation + modular experts + deployment flywheel
        ↓
(next) deployment failure → diagnosis → safe adaptation → selective reconstruction
```

Paper 002 sits in the **last layer** — not competing on foundation model scale.
